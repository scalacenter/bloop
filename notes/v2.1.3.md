# bloop `v2.1.3`

Bloop v2.1.3 is introduces a number of fixes and improvements:

- bugfix: List launcher commands in bloop --help and shell completions. [#3115]
- bugfix: Batch nailgun output so large run outputs are not truncated over
  TCP.[#3077]
- bugfix: Fix CommandsDocGenerator output after case-app 2.x migration. [#3113]
- bugfix: [sbt] Do not add evicted compile versions to the runtime
  classpath.[#3121]
- bugfix: [sbt] Export runtime-only dependencies in resolution. [#3072]
- refactor: Bloop will now cross publish Bloop rifle and cli for Scala 3 with
  default native image using Scala 3[#3112]
- bugfix: Fix server startup on Windows ARM64 .
- bugfix: Fix a memory leak in Bloop that would keep all previous compile
  results in memory.
- feature: Hard-link class files between classes directories instead of copying
  is now possible when setting the JVM option `-Dbloop.classes.hardlinks=true`.
  We plan to make this the default in a future release.
- bugfix: Release the check-pool thread when a Nailgun call times out
- feature: [bsp] Report the annotation processor output directory in
  buildTarget/sources
- feature: Add opt-in portable analysis files to support remote analysis
  caching.
- feature: Add --reverse-order flag to control CLI error output order
- bugfix: Use resources of source-less dependencies on compile classpath.
  [#3067]
- feature: [sbt] Tag custom sbt configurations that extend Test as test targets.
  [#3074]
- bugfix: Unlink stale BSP socket files before binding. [#3069]

## Installing Bloop

For more details about installing Bloop, please see
